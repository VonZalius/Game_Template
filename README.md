# 🎮 A GODOT GAME TEMPLATE — by MadeByQwerty

A clean, minimal, and easily extensible **Godot 4 game template**.  
This project provides a ready-to-use structure with menus, audio, and score handling —  
so you can jump straight into building your game without setting everything up from scratch.

---

## 🧩 Overview

**A Godot Game Template** includes the essential systems every project needs:
- 🎬 **Main Menu** – Navigate your game easily.
- 🎧 **Options Menu** – Adjustable **music** and **sound effect** volumes.
- 💀 **Game Over Screen** – A minimal template for handling game endings.
- 🎵 **Audio Management** – Pre-configured background music and SFX logic.
- 🧮 **Score Management** – Built-in in-game score tracking with a **high score menu**.
- 🧠 **Extensibility** – Easily expand with new options, menus, or mechanics.
- 🖼️ **AI-generated Backgrounds** – Placeholder visuals for quick prototyping.

Simple. Modular. Ready to go.

---

## 🚀 How to Use

### 1. Download or Clone the Repository
You can get the latest version from GitHub:
```bash
git clone https://github.com/VonZalius/MBQ_GameTemplate.git
```

Or download it directly as a ZIP and extract it.

### 2. Open in Godot 4
- Launch **Godot 4**  
- Click **“Import Project”**  
- Select the extracted folder and open it.

### 3. Customize
- Replace placeholder assets and background images.
- Add your own scenes and logic.
- Extend the menus with new options or transitions.

The template is intentionally **minimal**, so you can easily adapt it to any genre.

---

## ⚙️ Project Structure

| Folder / File | Description |
|----------------|-------------|
| `scenes/` | Contains main scenes (Main Menu, Options, Game Over, etc.) |
| `scripts/` | GDScript files managing menus, audio, and score logic |
| `assets/` | Placeholder images and sound files |
| `audio/` | Background music and sound effects |
| `main.tscn` | Entry point scene |
| `project.godot` | Godot project configuration |

---

## 🧠 Design Philosophy

This template is meant to **save time** when starting a new Godot game.  
It focuses on:
- **Simplicity** — clear, easy-to-understand code
- **Extensibility** — every system can grow as your project does
- **Flexibility** — works as a foundation for any 2D game

You can plug in UI transitions, level loading, or more advanced systems later — the base is already here.
